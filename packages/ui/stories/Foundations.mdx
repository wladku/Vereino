# Tokens

Vereino uses the Open Mercato design tokens unchanged (engineering standards S7.1, S7.2). Storybook imports them from
`packages/app/src/app/globals.css` and keeps no copy, so this page always shows what the app ships. Switch the theme in
the toolbar to see the dark values.

Rules that come with the tokens:

- Components use semantic classes (`bg-primary`, `text-muted-foreground`, `border-status-error-border`), never palette
  classes, arbitrary values or `dark:` overrides — `yarn ds:check` enforces it.
- A state is never shown by colour alone: every status colour comes with a word or an icon (WCAG 1.4.1).
- Icons are lucide line icons, the icon set of Open Mercato; they are decorative and the label carries the meaning.

## Radius and focus

- `--radius` is `0.625rem`; `rounded-sm`, `rounded-md`, `rounded-lg` and `rounded-xl` derive from it.
- Focus uses `--shadow-focus` (`--focus-ring-inner` and `--focus-ring-outer`), applied by the platform components on
  `:focus-visible`. Check it with the keyboard in each story; a container with `overflow: hidden` must not clip it.
