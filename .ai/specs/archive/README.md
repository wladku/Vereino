# Archived specs

Specs that were superseded by another spec or abandoned. A spec arrives here with `Status: Archived`, a Changelog row stating the reason and, if any, a link to its successor, moved from `.ai/specs/` with `git mv` (same `YYYY-MM-DD-slug.md` file name). Archived specs are never deleted; they record decisions that were tried or rejected.

Rules: `AGENTS.md` → **Project memory (`.ai/`)**.
