# D-009 Komunikaty w aplikacji + push/e-mail + „udostępnij na grupie”; bez integracji z Messengerem/WhatsApp
**Decyzja (propozycja):** aplikacja jest źródłem prawdy dla obecności, zmian, zastępstw, płatności; push + e-mail; przycisk generujący tekst z linkiem do wklejenia na grupę; magic link do deklaracji; czat w aplikacji tylko tam, gdzie potrzebny rejestr.
**Dlaczego:** brak oficjalnego API do grup Messenger/WhatsApp; WhatsApp Business 1:1 płatny i z szablonami.
**Żeby zmienić:** pojawienie się API do grup lub wynik rozmów, że rodzice nie klikną linku (H6).
**Wrócić:** po teście magic-linku w jednej grupie Gwiazdy.
