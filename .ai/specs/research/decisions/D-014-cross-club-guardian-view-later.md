# D-014 A guardian's view across several clubs is later, not 1.0

**Idea (Władek, 2026-10-23):** guardians often have children in different clubs. Władek gave the example of a friend with six children: two in the football academy and four at dance classes. When several of those clubs run Vereino, the guardian could see all their children's information in one app.

**Decision:** the cross-club view is recorded as a proposal for later. 1.0 does not build it, and 1.0 must not block it. Whether guardians actually struggle with children in several organisations is an open question for the parent interviews (the friend among them).

**Why:** this placement was Claude's recommendation, accepted by Władek. 1.0 runs one club per instance; multiple clubs on one instance is a non-goal whose architecture must not block it. The hosting model is still open (D-012). The benefit appears only when the other clubs also run Vereino. The problem behind the idea has no first-hand account yet; the friend's case is known only from Władek's description.

**Considered:** a calendar link that a guardian subscribes to in the phone's calendar, which puts Vereino sessions next to other clubs' classes without those clubs using Vereino. This was Claude's proposal; it was not chosen for 1.0 and stays an option for the same interviews to inform.

**To change:** parent interviews showing that keeping track of children across organisations is a frequent, costly problem.

**Revisit:** after the parent interviews scheduled on 2026-10-23.
